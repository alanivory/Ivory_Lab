OpenML Toolkit lowers the barrier to applying machine learning for practitioners outside of the ML field. Built on top of scikit-learn and SHAP, it provides a high-level, opinionated API with domain-appropriate abstractions and clear, human-readable model explanations.

## Key Goals

- **Accessibility**: Minimal ML prerequisite knowledge required
- **Interpretability first**: Every prediction comes with plain-language explanations
- **Error guidance**: Actionable suggestions when models fail or underperform
- **Domain presets**: Bundled configurations for biology, social science, and text analysis

## Status

Currently in active development with an early-access beta available on PyPI.
