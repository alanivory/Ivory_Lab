This website serves as my academic and professional home on the internet. Built with [Hugo](https://gohugo.io) and the [HugoBlox](https://hugoblox.com) resume theme, it is designed to be fast, accessible, and easy to maintain.

## What's Here

- **About**: Bio, education, work experience, skills, and awards
- **Projects**: Current and past research/engineering projects
- **Publications**: Peer-reviewed papers and preprints
- **Resume**: Downloadable PDF résumé

## Technology

- Static site generator: Hugo
- Theme: HugoBlox Resume
- Hosting: GitHub Pages / Netlify
- Source: Fully open source at [github.com/alanivory/Ivory_Lab](https://github.com/alanivory/Ivory_Lab)
